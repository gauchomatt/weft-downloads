# Weft downloads

Official signed and notarized Weft installers and the signed in-app update feed.
This repository contains distribution files only; application source is maintained separately.

Download the latest installer from [Releases](https://github.com/gauchomatt/weft-downloads/releases/latest), open it, and drag Weft to Applications.

Once installed, use **Weft → Check for Updates…**. Background update checks can be enabled in Settings. Weft asks before installing an update.

Older builds through 1.0.52 need one manual installation to enable in-app updates.

Requires macOS 26 or later and Apple silicon.
